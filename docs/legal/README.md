# 規約・プライバシーポリシーの運用

| ファイル | 内容 | 公開URL（main に push した後） |
|---|---|---|
| `public/legal/terms.html` | 利用規約 | `https://yusuke827827.github.io/jp-speed-reader/legal/terms.html` |
| `public/legal/privacy.html` | プライバシーポリシー | `https://yusuke827827.github.io/jp-speed-reader/legal/privacy.html` |

`public/` に置いたファイルは、`.github/workflows/deploy.yml` によって GitHub Pages にそのまま公開されます。PWA の Service Worker が、これらのページを SPA の `index.html` に置き換えないよう、`vite.config.ts` の `navigateFallbackDenylist` で除いています。

## 公開の前に必ずやること

1. **黄色の穴埋め箇所を埋める。** 残りは次のコマンドで探せます。

   ```bash
   grep -rn '【' public/legal
   ```

   | 穴埋め | 内容 |
   |---|---|
   | `【運営者名】` | 個人の場合は、氏名または屋号 |
   | `【連絡先メールアドレス】` | 公開されるので、専用のアドレスを推奨 |
   | `【施行日】` | 公開する日 |

   このリポジトリは公開です。住所や電話番号は書かないでください（無料のアプリでは、規約への記載は必須ではありません）。
2. ポリシーの記述が、アプリの実際の動きと合っているかを確かめる（下の「実装との対応」）。
3. 弁護士に1回レビューしてもらう（3本共通のひな形として、1セットで足ります）。見てもらう点は、免責（第11条）、ストア経由の入手（第13条）、管轄（第14条）です。

## 実装との対応（2026年10月時点で確認）

| ポリシーの記述 | 実装 |
|---|---|
| 運営者のサーバーに本文や画像を送らない | `src/` に外部送信はなく、`fetch` はサンプル文書の取得（`src/ui/Import.tsx`）だけ |
| OCR の学習データは CDN から取得 | `vite.config.ts` の `cdn.jsdelivr.net`（`tesseract.js-data`）。OCR を使うときだけ |
| iOS 版は外部と通信しない | `ios/` に `URLSession` や URL の指定がない |
| アクセス解析・広告・Cookie を使わない | 該当するコードや依存パッケージがない |

**次のどれかを足すときは、足す前に、ポリシーと規約を改定してください**（`legal-ops` エージェントに点検を頼めます）：アクセス解析、クラッシュ報告、広告、アカウント、クラウド同期、課金、サーバー通信。

## ストアに出すときの入力

- **プライバシーポリシーのURL：**上の公開URL。iOS 版には、アプリ内からも開ける導線を付ける（App Store の審査で求められます）。
- **App Store のプライバシー回答（App Privacy）／Google Play のデータ セーフティ：**現状は「データを収集しない」を想定。ただし、Web 版の CDN（jsDelivr）への要求が収集に当たるかは、回答前に確認する。iOS 版は外部通信がないので問題になりにくい。
- **利用規約：**Apple の標準使用許諾契約を使うか、独自の規約を使うか選べます。独自の規約を使う場合は、Apple が求める最低限の条項が必要で、第13条がそれに当たります。

## 有料化するときに見直す点

規約の第10条は、有料の機能を加えるときに改定する前提で書いてあります。有料化の前に、次を用意してください。

- 価格・内容・返金／解約の案内
- 特定商取引法に基づく表記（個人の場合の住所・電話番号の扱いは、消費者庁の案内で確認）
- 税務の準備（`docs/business/README.md` の `tax-advisor`）

## 他のアプリ（hikidashi、kintore-app）へ

この2つのファイルをコピーして、アプリ名と、次の点を、そのアプリの実際の動きに合わせて書き換えてください。

- 保存する情報と、その保存先
- 外部との通信（API、解析、広告があるなら、その相手と送る内容）
- アプリの機能に固有の注意（健康・運動など、利用上の注意の内容が変わる）

`legal-ops` エージェントに、「コードを調べて、`public/legal/` のひな形を、このアプリ用に書き換えて」と頼めます。
