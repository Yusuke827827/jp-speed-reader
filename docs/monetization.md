# Flowa の収益化の計画

Flowa を「小さく作って、積み上がる収入」にするための計画です。数字はすべて仮定にもとづく目安で、出してから実際の数字で直します。

## 方針

| 項目 | 決めたこと | 理由 |
|---|---|---|
| 売る場所 | iOS 版を App Store で売る。Web 版は無料の体験版と宣伝の入口にする | お金を払う人は App Store で探す。Web 版は検索・SNS から試してもらえる |
| 料金の形 | 基本無料＋「Flowa Pro」の買い切り（初期案 1,200 円）。あとで年額（初期案 年 1,500 円）を試す | 本文も設定も端末の中だけに保存し、サーバーを持たないので、利用者が増えても費用が増えない。買い切りでも赤字にならず、「サブスク疲れ」の人にも売りやすい |
| 強み | 日本語の縦書き PDF・青空文庫・ルビ・人物の色分けに対応した速読アプリ | 英語の速読アプリ（RSVP 型）は多いが、日本語の縦書きの小説をきちんと読めるものはほとんどない |
| 費用 | Apple Developer Program 年 99 ドル（約 1.5 万円）。App Store の手数料は Small Business Program で 15% | ほかに固定費はない |

## 無料と Pro の分け方（案）

「速読そのもの」は無料で十分に体験でき、「たくさん・快適に読む人」が払いたくなる線で分けます。

| 機能 | 無料 | Pro |
|---|---|---|
| 高速読書（5 種類の分割・速度・縦書き表示） | ○ | ○ |
| サンプル・青空文庫のテキストの取り込み | ○ | ○ |
| 本棚に置ける PDF の冊数 | 3 冊まで | 無制限 |
| 画像だけの PDF の文字認識（OCR・Vision） | 1 冊につき 10 ページまで | 無制限 |
| 人物の登録・色分け・説明 | — | ○ |
| 読書の履歴と統計 | 直近 7 日 | すべて |
| 模様のある配色（和紙・夜空・オーロラ・羊皮紙） | — | ○ |
| 英語の本の WPM 設定 | ○ | ○ |

青空文庫を無料にしておくのは、「著作権の切れた名作をタダで速読できる」が、そのままストアの説明や SNS で使える分かりやすい売り文句になるからです。

## 収入の目安

| | 控えめ | 中くらい | うまくいった場合 |
|---|---|---|---|
| 月のダウンロード | 300 | 1,500 | 6,000 |
| Pro を買う割合 | 2% | 4% | 5% |
| 月の売上（1,200 円、手数料 15% を引いた額） | 約 6,000 円 | 約 6 万円 | 約 30 万円 |

最初の数か月は「控えめ」を想定してください。買い切りの売上はダウンロード数に比例するので、伸ばすのは主に**ストア検索と発信**です。日本語版で反応が良ければ、英語の論文・洋書向け（2 段組み・参考文献を飛ばす機能はすでにある）として英語圏のストアにも出し、母数を増やします。

## やること（最初の 30 日）

### 1 週目：出す準備
- [ ] Apple Developer Program に登録し、`ios/FlowaApp/project.yml` の仮の ID（`app.flowa.reader`）を本番の ID に変える
- [ ] Web 版を Cloudflare Pages か GitHub Pages で公開する（README の「iPhoneで使う」の手順）
- [ ] プライバシーポリシーの 1 ページを作る（「本文・PDF は端末の外に送らない」と書けるのが強み）

### 2 週目：Pro を作る
- [x] StoreKit 2 で買い切りの Pro（非消耗型、商品 ID `app.flowa.reader.pro`）を 1 つ作り、上の表のとおりに機能を分ける（iOS 版にまだ無い OCR・人物・履歴は、加えるときに上限を付ける。[`ios/README.md`](../ios/README.md) の「Flowa Pro」）
- [x] 購入の復元ボタンと、無料の上限に達したときに出す案内の画面を作る
- [ ] App Store Connect で同じ商品 ID の App 内課金を登録し、値段（1,200 円）を設定する
- [ ] TestFlight で知り合い 5〜10 人に使ってもらい、どこで止まるかを聞く

### 3 週目：ストアのページ
- [ ] 名前と副題に検索される言葉を入れる（例：「Flowa - 速読・縦書きPDFリーダー」）。キーワード候補：速読、読書、PDF、縦書き、青空文庫、小説、集中、読書記録
- [ ] スクリーンショット 5 枚：中央表示の速読、縦書き、ルビ、人物の色分け、読書の履歴
- [ ] 15〜30 秒の画面録画（1 文字ずつ流れる様子は短い動画で伝わりやすい）

### 4 週目：出して、発信する
- [ ] App Store に申請して公開する
- [ ] 作ったものと作る過程を X・Zenn・note に出す（「縦書きの PDF から段落を組み立てる仕組み」など、技術記事は検索から長く読まれる）
- [ ] 速読の様子の短い動画を TikTok・YouTube ショート・X に出す（「青空文庫の『走れメロス』を〇分で読む」など）

## 出したあとに見る数字

| 数字 | 見る場所 | 目安 |
|---|---|---|
| ストアのページを見た人のうちダウンロードした割合 | App Store Connect | 30% 未満ならスクリーンショットと説明を直す |
| ダウンロードした人のうち Pro を買った割合 | App Store Connect | 2% 未満なら無料の範囲が広すぎるか、Pro の良さが伝わっていない |
| 星の数とレビューの内容 | App Store | 不満の多いところから直す |

## まだ決めていないこと

- Pro の値段（1,200 円は仮。同じ種類のアプリの値段を見て決める）
- 年額を最初から用意するか、買い切りだけで始めるか
- 無料版の冊数・ページ数の上限
