# GLOBAL_STRATEGY.md — 海外展開・多言語化計画

最終更新: 2026-11-05

## 1. 進出の順番（アプリ別）

| 順 | 筋トレ | Mindrawer | Flowa |
|---|---|---|---|
| 1 | **日本**（差別化が効く主戦場） | **日本**（日本語の文脈・X 文化） | 日本（縦書き・ルビは日本語専用の価値） |
| 2 | 米国・英国・カナダ・オーストラリア（英語版の掲載文はほぼ準備済み → 追加費用が小さい） | 米国（英語 UI 済み。ただし競合 mymind/Recall が強いので ASO テストのみ） | 英語は保留（英語 RSVP はクローン過多） |
| 3 | 韓国・台湾（「韓国アイドル体型」は韓国・台湾でも刺さる可能性【仮説】） | 台湾・香港（繁体字） | 台湾（縦書き文化がある【仮説】） |
| 後回し | ドイツ・フランス（翻訳・競合を見て） | ドイツ（プライバシー訴求が強い市場【仮説】） | — |

**判断基準**: 1) その国で差別化が効くか 2) 翻訳・ASO の追加コスト 3) 課金単価。最初から全世界に出す必要はないが、**App Store は「配信国」を全世界にしておき、ストア掲載文の言語だけを絞る**のが手間が少なく取りこぼしもない（価格は自動換算）。

## 2. 多言語対応の状況

| | 日本語 | 英語 | 簡体字 | 繁体字 | 韓国語 |
|---|---|---|---|---|---|
| 筋トレ UI | ✅ | ✅（959行の訳） | ❌ | ❌ | ❌ |
| 筋トレ ストア掲載文 | ✅ | ✅（`appstore/listing.md`） | — | — | — |
| Mindrawer UI | ✅ | ✅ | ❌ | ❌ | ❌ |
| Mindrawer 掲載文・規約 | ✅ | ✅ | — | — | — |
| Flowa UI | ✅ | ✅ | ❌ | ❌ | ❌ |

**翻訳の方針**
- 機械翻訳そのままにしない。AI で下訳 → 「現地のアプリでよく使う言い回し」に合わせて直す（例: 「マイセット」→ 英語は "Routines"、「回復マップ」→ "Muscle recovery"）。
- 韓国語・繁体字は、**ストア掲載文とスクショの見出しだけ先に翻訳**し、インストール数が出たら UI を翻訳する（安いテスト）。
- 単位: 米国は lb・ft/in、食事は kcal。筋トレは kg/lb 切り替えがあるか要確認（無ければ英語圏展開前に必須）。

## 3. 国ごとの価格
MONETIZATION_PLAN.md §2-5 を参照。App Store / Google Play の価格帯から選び、**為替で自動換算された中途半端な価格（例 $2.99 → ¥450 等）を避けて主要国は手で設定**。

## 4. 海外特有の規制・確認事項

| 項目 | 内容 | 3アプリへの影響 | 対応 |
|---|---|---|---|
| GDPR（EU/英国） | 個人データの処理には根拠・説明・削除手段が必要 | 3アプリとも端末内保存が中心で影響小。Mindrawer の同期・共有・AI 送信は説明が必要 | プライバシーポリシーに処理目的・保存期間・送信先（Anthropic 米国）・削除方法を明記 |
| 米国州法（CCPA/CPRA 等） | 「個人情報の販売・共有」の開示とオプトアウト | 広告を入れなければほぼ対象外 | 広告導入時に再確認 |
| ATT（iOS 追跡許可） | 他社データと結び付ける追跡には許可が必要 | 広告なし・分析を自社のみにすれば不要 | 広告導入時のみ |
| Cookie 同意（Web 版） | EU の Web サイトでの追跡 Cookie | 解析を入れていないので現状不要 | 解析ツール導入時に検討 |
| 健康データ（HealthKit） | 広告・データ販売への利用禁止（Apple 規約） | 筋トレ: 端末内でのみ使用 | 審査メモとポリシーに明記 |
| 税金（消費税・VAT） | Apple/Google が各国の消費税・VAT を代行納付 | 開発者は申告不要の国が大半【要確認】 | 日本の消費税: 年間売上 1,000 万円超で課税事業者。**インボイス・国外取引の扱いは税理士に確認** |
| 米国の源泉税 | W-8BEN を出さないと 30% 源泉 | 日米租税条約で軽減 | App Store Connect / Play Console で W-8BEN 提出 |
| アプリ内課金の地域ルール | 米国（外部リンク）、日本（MSCA）、EU（DMA）、韓国（代替決済） | 小規模では標準課金が最も安く簡単 | MONETIZATION_PLAN §2-3 |
| データの保存場所 | 一部の国は国外移転に条件 | Mindrawer の Cloudflare（世界分散）・Anthropic（米国） | ポリシーに「米国等に送信」と明記 |
| AI API への送信 | 利用者のメモ・スクショを第三者（Anthropic）へ | Mindrawer | 初回 AI 利用時に同意画面（何を送るか）、Anthropic の商用規約では API データは学習に使わない旨を確認して記載 |

## 5. 専門家に確認すべき事項（税理士・弁護士）
1. 個人事業の開業届・青色申告の要否、ストア収益の売上計上時期（入金日 or 販売月）。
2. 国外ストア売上の消費税の扱い（国外取引か、Apple/Google 経由の扱い）、インボイス登録の要否。
3. 年 20 万円超の副業所得の申告（会社員の場合）。
4. 利用規約の免責（筋トレ: 怪我、食事: 医療行為でない旨）の文言レビュー。
5. EU 向けにデータ保護の代理人（Art. 27）が必要になる規模か。
